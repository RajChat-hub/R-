# Dependencies and licensing

Original first-party C++ code: Copyright (c) 2026 SalesAutoMate. Commercial licensing decision pending owner approval. No project-wide open-source licence has been assigned.

The server runtime uses C++ standard library, POSIX threading and Linux libc/kernel interfaces (including epoll, signalfd and eventfd). It does not embed an existing HTTP parser, web server, event loop or custom cryptographic implementation. No copied third-party source is vendored.

Build/test tooling: GCC (toolchain licensing, including its runtime-library exception where applicable), CMake/CTest (BSD-3-Clause distribution), Python (PSF distribution), clang-format (Apache-2.0 with LLVM exceptions). These tools are not redistributed with the source package. GitHub Actions uses runner-provided Git for public read-only sparse checkout; no third-party action is required. Future binary packaging must review the licences and notices for actual linked runtime libraries; source-only inventory is not a completed binary redistribution/legal review.

OpenSSL libssl/libcrypto 3.x are now linked for cryptography and TLS only. OpenSSL project copyright and Apache License 2.0 apply to that dependency; see third_party/OpenSSL-APACHE-2.0.txt and https://github.com/openssl/openssl/blob/master/LICENSE.txt. No OpenSSL source or binaries are vendored. System package versions and maintenance policy are recorded in docs/operations/TLS.md and the CI logs. API minimum 3.0 is not a security patch guarantee; use actively maintained distribution packages or a supported upstream LTS and track advisories. Dynamic or static binary distribution must include the applicable OpenSSL license/notice materials plus the actual linked runtime dependencies' obligations; commercial binary redistribution has not been approved. Test credentials are generated locally into temporary/ignored directories only. No private keys or real credentials are committed.
